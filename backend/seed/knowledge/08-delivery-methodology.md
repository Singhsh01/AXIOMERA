# Phases
Implementations follow five phases: discovery (4 weeks), configuration in two-week sprints, data migration, training, and hypercare (6 weeks after go-live).

# Governance
A joint steering committee meets monthly; a project board meets every two weeks. Risks, decisions and changes are tracked in a shared register.

# Team
A typical project team consists of a project manager, a solution architect, two to four configuration engineers, a migration specialist and a change and training manager.

# Training
Train-the-trainer programmes, e-learning modules and role-specific caseworker training are provided in German and English.
