# On-premises deployment
HelixFlow is not available as an on-premises installation. We do not offer on-premises deployment; the platform is provided exclusively as a managed cloud service hosted in the European Union.

# Data processing agreement
Helix Ridge signs customer data processing agreements in accordance with Article 28 GDPR. Our standard agreement can be replaced by the customer's own agreement after legal review.

# Support
Standard support is available Monday to Friday, 8:00 to 18:00 CET. Premium support adds 24x7 coverage for priority 1 incidents with a response time of 30 minutes.

# Source code escrow
A source code escrow agreement with a recognised escrow agent is available on request.

# Exit and data return
At contract end, all customer data is exported in open formats (CSV, JSON, PDF) and deleted within 30 days after confirmation.
